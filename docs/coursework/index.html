EECS 491

Introduction to Distributed Systems

Principles behind systems that span many machines: remote procedure calls, concurrency and consistency models, replication, fault tolerance, and consensus.

Course projects

  • Simple Key/Value StoreA linearizable key/value server and client with exactly-once writes across client retries, able to serve reads while a write is still going to disk, synchronized with nothing but unbuffered channels.
  • Primary/Backup Key/Value ServiceA view service that picks the primary and backup, and a replicated key/value service that forwards every operation to the backup, transfers state to a new backup on failover, and prevents split brain under network partitions.
  • Paxos-based Key/Value ServiceA Paxos library running many agreement instances concurrently, a replicated log built on it, and a key/value service that keeps working as long as a majority of replicas can reach each other.

Code private per course policy.

Winter 2026

EECS 482

Introduction to Operating Systems

Core operating system concepts including thread scheduling and synchronization, virtual memory, file systems, and the fundamentals of distributed systems.

Course projects

  • Multithreaded Pizza Delivery Matching, individualA concurrent program in which every driver and customer is its own thread. Each request is matched only with a driver that is among the closest to it, and vice versa, while any number of drivers drive at once. Synchronized with mutexes and condition variables alone.
  • Thread Library, team of 3The thread library Project 1 ran on: threads, mutexes, and condition variables built on raw execution contexts, with FIFO scheduling, preemption by timer interrupts, and errors raised for misuse. Shipped with a test suite graded on how many deliberately buggy libraries it caught.
  • Virtual Memory Pager, team of 3The part of the kernel that manages processes’ address spaces: swap-backed and file-backed pages, clock (second-chance) eviction, copy-on-write sharing across fork, and a pinned zero page, all designed to put off or avoid disk I/O and page copies.
  • Network File Server, team of 3A multithreaded file server that takes requests over TCP sockets and stores a hierarchical file system of inodes and directory entries. Per-file reader/writer locks with hand-over-hand locking let safe requests run in parallel, disk writes are ordered so a crash never corrupts the file system, and untrusted requests are parsed defensively.

Code private per course policy.
