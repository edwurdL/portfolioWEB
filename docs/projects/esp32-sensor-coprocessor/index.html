ESP32 Sensor Coprocessor for Position Tracking

Third-party VL53L1X time-of-flight sensors read over I2C by an ESP32 coprocessor, streamed over serial to the main robot controller to validate position tracking.

Status
Completed
Date
Jun 2026
Built with
ESP32, I2C, Embedded, Sensors, Robotics

I wanted VL53L1X time-of-flight distance sensors on the robot, but its controller has no native support for them. So I brought them in anyway, using an ESP32 as a dedicated sensor coprocessor, and then used their readings to check how well the robot’s position tracking holds up.

The coprocessor

The ESP32 drives the sensors over I2C, handling device addressing, configuration, and ranging timing. It forwards the readings to the main robot controller over a serial link. That keeps all the sensor I/O off the controller’s main loop, which only has to read finished measurements.

Checking position tracking

The distance measurements gave me an independent reference for the robot’s position. By comparing the robot’s reported pose against measured distances to fixed field elements, I could confirm that the tracking held up over the length of a match.
