LEAP Hand Reinforcement Learning

A summer project to learn Linux by recreating the LEAP Hand reinforcement learning setup on ROS 2, debugging the wiring and code until training and testing ran on the real hand.

LinuxROS 2PythonReinforcement LearningRobotics

This was the summer after my freshman year. The point wasn’t new research: it was to learn Linux, set up a working environment in it, and get a real robotics project running end to end. The project I picked was reinforcement learning on the LEAP Hand.

The LEAP Hand

The LEAP Hand comes from Kenneth Shaw, Ananye Agarwal, and Deepak Pathak at Carnegie Mellon University, published at RSS 2023 (project page). It’s a low-cost, anthropomorphic hand: it costs under $2,000, about an eighth of the price of the Allegro Hand, its closest competitor. Its kinematic structure is designed to stay as dexterous as possible whatever pose the fingers are in.

Recreating the setup

I didn’t design anything new here. My job was to recreate the research setup so that it ran correctly, and that’s where most of the learning happened: working in Linux and ROS 2, setting up virtual environments, and sorting out compatibility between all the pieces so everything ran the way it should. Getting the hand itself working took some debugging too, both in the wiring and in the Python file that runs it.

Partway through I had to switch computers. I’d been working in a virtual machine, and it couldn’t run training, which needs a GPU. Rather than set up vSphere to get the virtual machine a GPU, it was simpler to install Linux as a second boot on a PC with one and carry on there.

Training and testing

Once everything was set up, the reinforcement learning itself was straightforward: I ran the training script, let it run, and then tested the result on the hand.
